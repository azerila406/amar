# Statistics and Its Applications

This project studies how entorhinal cortex thickness relates to cognitive and functional difficulties in the NACC data.

- [Project card](PROJECT_CARD.md)
- [Phase 1 report](reports/phase1.pdf) and [notebook](phase1.ipynb)
- [Phase 2 report](reports/phase2.pdf), [notebook](phase2.ipynb), [tables](tables/phase2/), and [figures](figures/phase2/)

## Run the notebooks

Put `alzheimer(1).zip` next to the notebooks. See the [data guide](data/README.md) for the files inside it.

```sh
python -m pip install notebook numpy pandas matplotlib
jupyter notebook
```
